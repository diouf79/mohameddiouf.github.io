Passionné par le code, obsédé par les détails.

Je suis Mohamed Diouf, développeur Fullstack & Mobile basé à Dakar, Sénégal. Je conçois et développe des applications web et mobiles à fort impact — du frontend ultra-soigné aux architectures backend robustes.

Ma philosophie : chaque ligne de code est une opportunité de créer quelque chose d'extraordinaire. Je m'inspire des meilleures pratiques mondiales pour livrer des produits qui dépassent les attentes.

Quand je ne code pas, j'explore les nouvelles technologies, contribue à l'open source et partage mes connaissances avec la communauté tech africaine.
